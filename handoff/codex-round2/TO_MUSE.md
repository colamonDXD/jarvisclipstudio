# SnipNova live clip quality release

Apply the numbered Git patches in order to the extracted V13 FAST baseline. The development branch is `feature/live-quality`. The original installer digest is `00766a61675af0e268d55475daa15c32ffefd705c479ecf4f4dfcd15b9a413f8`.

## Editing and speech

- The Live page previews and saves 11 layouts with hand-drawn face and gameplay regions. Gameplay-only and full-frame layouts accept footage without a visible facecam. The source includes attribution for NeonClipping's MIT layout geometry. [NeonClipping](https://github.com/iamajmeena/neonclipping)
- Per-clip titles, title overrides and a no-title option feed the renderer. Styled titles wrap in gold at the top. The renderer can use a short punch cut with a quiet pop for laughter and a stronger eased zoom with an impact for shouts. The added sound ducks when the original audio is loud. Gaming captions can accent numbers and game terms in green while keeping the active word yellow.
- Game subtitles previously suppressed every overlapping spoken word. The worker now uses local OCR and matches consecutive phrases to the transcript. On the 57.52-second Kai example, both runs started with 126 ASR words. The previous filter kept 50 and the new filter kept 85. This is a retention count. Human transcription accuracy and speaker identity still need review on overlapping game dialogue.
- YouTube word timings follow the teaser and then the full clip in a cold open. A real run revealed that a 57-second source could yield a 29.51-second export. The corrected run preserved 59.50 seconds including its teaser, and the finished export measured 59.10 seconds. The worker validates the duration after rendering and can try a reserve candidate.
- Finished live recordings can be saved to the library. Each import retains the export, an independent editable source and available word timings. The same clip can be saved repeatedly without creating duplicate library entries. The create form exposes voice separation when the backend reports the feature is enabled.
- The free gateway routes text requests through NVIDIA, Groq, OpenRouter free models and local Ollama. A forced provider failure reached OpenRouter. A synthetic editor command successfully produced the typed operation to set audio volume to 0.5. The local Whisper large-v3 speech path uses a dedicated read-only CUDA runtime volume. It recognized 106 words on the 57-second sample with networking disabled. [faster-whisper](https://github.com/SYSTRAN/faster-whisper)

## Picking moments

The data folder contains per-second audio features and public YouTube replay labels from 32 recordings. It contains the split and the comparison results. The 26 reference Shorts are a separate editing study. Four gaming references had 10.7–26.5 million recorded views. Their median cut rate was 3.5 per minute. The three unique supplied exports had a median of 14.4. The reference clips showed more motion in the first two seconds. The sample supports trying a clearer opening action before adding cuts. [Gaming reference](https://www.youtube.com/shorts/Ec18vXsDHYU)

The context picker measures audio before, during and after the reaction. It trained on 12 recordings and selected its blend on six. On the next six, the replay score increased from 0.480 to 0.554 without replay labels at inference. On a further eight recordings, it decreased from 0.519 to 0.514. With replay heat available on those eight, it decreased from 0.616 to 0.581. The installed picker stays the default. Set `LIVE_CONTEXT_PICKER=on` to try the challenger.

On four shared public recordings, NeonClipping's local first-stage finder scored 0.574, SnipNova's current default scored 0.450 and the experimental context picker scored 0.549. Each system received the same requested clip count. The test scored the first 20 seconds against source replay percentiles, with replay heat withheld from the pickers. NeonClipping also uses visual motion, cuts and audio spikes. These numbers cover first-stage selection only. Published features from OpusClip and Klap were reviewed separately. A blinded same-source final-export comparison with both commercial products remains open. [NeonClipping ranker](https://github.com/iamajmeena/neonclipping/blob/main/highlights.py) · [OpusClip](https://www.opus.pro/clipanything) · [Klap](https://klap.app/)

## Verification

The V13 installation passed 218 checks. The final targeted regression run passed 319 backend and 38 frontend tests, plus TypeScript checking. All 11 manual layout graphs produced real FFmpeg frames. A GPU render check produced eight seconds of video and audio for each of the laugh, shout and neutral treatments. Full upstream regression and human listening tests remain outstanding.

The local speech runtime is installed separately from the source patches. Use `tools/live/prepare_offline_whisper.py` with a local CTranslate2 large-v3 snapshot on a GPU-capable installation, then enable `LIVE_OFFLINE_WHISPER`. A number of original recordings contain long stretches with little recognized speech. Neither the audio-energy coverage indicator nor a second speech recognizer provides a reference transcript.

The real 11.6-hour Kai VOD test selected three moments and produced 53.93, 52.90 and 58.10 seconds of playable output in 21 minutes. Frame inspection caught a YouTube speaker-change marker and a headline that attributed game dialogue to the streamer. The subsequent fixes passed 41 caption and renderer checks and 40 VOD and finisher checks. These focused runs overlap the main suite. Gaming headlines now require a scene phrase grounded in the words and keep the streamer in the observer role. Automated speech accuracy on music and simultaneous voices remains variable.
The three final review exports measured 53.80, 52.47 and 58.10 seconds. All contained H.264 at 1080 by 1920 and AAC audio, and all three were saved to the installed Clips library. The second sample retains a music cue in its burned-in opening captions. Subsequent renders remove bracketed non-speech cues while preserving the spoken word music. The caption parser passed all 12 focused checks.
